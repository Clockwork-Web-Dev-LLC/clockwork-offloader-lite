# Screenshots

This folder contains screenshots for the WordPress.org plugin repository.

## Screenshot Requirements

1. **screenshot-1.png** - Dashboard with statistics
   - Shows the main dashboard with offload statistics
   - Displays system status and URL preview

2. **screenshot-2.png** - Settings page
   - Shows the settings configuration interface
   - Displays credential storage options

3. **screenshot-3.png** - Bulk offload interface
   - Shows the bulk offload tool
   - Displays batch processing options

4. **screenshot-4.png** - Setup wizard
   - Shows the 3-step setup wizard
   - Displays the configuration process

## Technical Requirements

- **Size**: 1200x900 pixels (4:3 aspect ratio)
- **Format**: PNG
- **Quality**: High quality, optimized for web
- **Theme**: Use default WordPress theme (Twenty Twenty-Four or similar)
- **Content**: Use sample/demo data, no real credentials or sensitive information

## How to Create Screenshots

1. Set up a clean WordPress installation
2. Install and activate the plugin
3. Configure with demo/test credentials (not real)
4. Take screenshots using browser developer tools or screenshot tool
5. Crop to 1200x900 pixels
6. Optimize images (use tools like TinyPNG or ImageOptim)
7. Save as PNG files with proper naming
