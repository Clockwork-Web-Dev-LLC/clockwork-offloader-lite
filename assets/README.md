# WordPress.org Assets

This folder contains assets for the WordPress.org plugin repository.

## Required Files

### Banner
- **File**: `banner-772x250.png`
- **Size**: 772x250 pixels
- **Format**: PNG
- **Description**: Plugin banner displayed on the plugin page. Should be visually appealing and represent the plugin's purpose.

### Icon
- **File**: `icon-256x256.png`
- **Size**: 256x256 pixels
- **Format**: PNG
- **Description**: Plugin icon displayed in search results and plugin directory. Square format, should work well at small sizes.

## Screenshots
